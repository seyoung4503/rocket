# 하드웨어 설계

시뮬레이션 우선 진행하되, 하드웨어 설계를 병행한다. 시뮬레이터의 파라미터
([`src/rocketsim/vehicle.py`](../src/rocketsim/vehicle.py))는 아래 실기 사양과 1:1로 대응시켜 sim-to-real 격차를 줄인다.

## A. Phase 1 — EDF 호버/착륙 테스트베드

목표: 마하 1과 무관한 **저속·안전**한 기체로 PID↔RL 자세/착륙 제어를 검증.
구조적으로 추력편향 헬리콥터 호버와 동일한 문제.

### A.1 추진 (Propulsion)
- **EDF 유닛**: 70–90 mm 클래스, 6S 기준 정적 추력 3–5 kgf.
  - 시작점: 90 mm EDF + 6S, 정적 추력 ≈ 40 N (`max_thrust=40`).
  - 추력대중량비(TWR) 목표 1.5–2.0 → 전비중량 2.0–2.7 kg.
- **ESC**: EDF 정격 이상(예: 100–120 A), 텔레메트리(RPM/전류) 지원 권장.
- ⚠️ 주의: EDF는 **스풀업 지연**(0.05–0.15 s)이 커서 추력으로 자세를 빠르게 못 잡음.
  자세는 **김벌(TVC)** 로, 고도는 스로틀로 분리 제어. (`thrust_time_constant=0.08`)

### A.2 추력편향 (TVC / 김벌)
- **2축 김벌 마운트**: EDF 노즐 또는 유닛 전체를 pitch/yaw로 ±10–15° 편향.
  - 시작점: ±12° (`gimbal_limit`), 액추에이터 슬루 ~200°/s (`gimbal_rate_limit`).
- **액추에이터**: 디지털 서보 2개(고토크·고속, 예: ≥10 kg·cm, ≤0.06 s/60°).
- **김벌 피벗–CG 거리**가 제어 토크 레버암(`engine_offset=0.45 m`). 길수록 토크 ↑, 관성 ↑.
- **롤 제어**: 단일 김벌로는 롤(기체 축 회전) 제어 불가.
  - 옵션: (1) 고정 안내깃/베인, (2) 소형 리액션휠, (3) 카운터-로터 EDF. Phase 1은 롤을 수동적으로 안정화(낮은 무게중심 + 항력)하고 제어 대상에서 제외.

### A.3 항공전자 (Avionics)
- **비행 컨트롤러(FC)**: STM32H7 급 (예: 커스텀 보드 또는 PX4/Betaflight 호환 H7).
  - 제어 루프 500 Hz–1 kHz (시뮬레이터 dt=0.002 = 500 Hz와 정합).
- **센서**:
  - IMU: 가속도+자이로 (예: BMI088/ICM-42688), 자세 추정용.
  - 자력계: 요(yaw) 드리프트 보정 (옵션).
  - 고도: 기압계(저고도엔 부정확) + **ToF/레이저 거리계**(지면 기준 정밀 고도) → 착륙에 필수.
  - GPS: 실외 위치 유지(옵션, 실내 테스트엔 불가).
- **상태 추정**: EKF로 IMU+거리계 융합 → (위치, 속도, 자세, 각속도) = 시뮬레이터 상태와 동일 구조.

### A.4 전력 (Power)
- **배터리**: 6S LiPo, EDF 전류·비행 시간 기준 용량 산정(예: 5000 mAh). 호버 1–2분 수준.
- FC/서보용 BEC 5V 분리. 전류·전압 텔레메트리로 추력 곡선 실측 → 시뮬 교정.

### A.5 구조 (Structure)
- **기체**: 직경 ~10 cm 탄소/유리 튜브 또는 3D 프린팅 프레임 (`ref_area≈0.0079 m²`).
- **착륙장치**: 접이식 다리 3–4개, 착지 충격 흡수.
- **무게중심**: 가능한 낮게(배터리를 하부) → 수동 안정성 ↑.
- **안전**: 테스트 초기엔 **테더(끈) 고정** 또는 짐벌 테스트 스탠드로 6-DOF 중 일부만 개방.

### A.6 시뮬레이터 ↔ 실기 파라미터 매핑
| 시뮬 파라미터 | 의미 | 실측/교정 방법 |
|---|---|---|
| `mass` | 전비중량 | 저울 |
| `inertia` | 관성텐서 | CAD 추정 → 진자 실험 보정 |
| `max_thrust` | 최대 추력 | 추력대(load cell) 측정 |
| `thrust_time_constant` | 스풀업 지연 | 스텝 응답 로깅 |
| `engine_offset` | 김벌–CG 거리 | 실측 |
| `gimbal_limit/rate` | 김벌 한계/속도 | 서보 사양·실측 |
| `drag_coeff·ref_area` | 항력 | 풍동/낙하 실험(저속이라 영향 작음) |

## B. Phase 2 — 고체 모터 TVC 호퍼 (아음속)
- 고출력 고체 로켓 모터(예: 상용 단일 사용 모터) + 내열 TVC.
- 연소 중 **질량 감소** → 시뮬레이터에 가변 질량/관성 추가 필요.
- 법규: 고출력 로켓 인증, 승인 발사장, 화공품 취급 안전.

## C. Phase 3 — 마하 1 비행체 (별도 기체)
- 마하 1(≈343 m/s)은 고체/액체 로켓 추진 필요. EDF 불가.
- 천음속 공력(압축성, 충격파) → 시뮬 공력 모델 고도화 필요.
- 1차 회수는 낙하산. 동력 역추진 착륙 결합은 장기 연구.

### 추가사항 — 2026-05-29 17:04 KST — 음속 돌파 형상 검토

음속 돌파는 "추력을 키우면 되는 문제"가 아니라 **형상·공력·구조·추진 방식**이 같이 맞아야 하는 별도 비행체 문제다.

마하 1 근처에서 기본 항력은:

```text
D = 0.5 * rho * V^2 * Cd * A
```

이고, 마하 0.8~1.2에서는 충격파 때문에 `Cd`가 급증할 수 있다. 따라서 아래 항목을 별도 설계해야 한다.

| 항목 | 검토 이유 |
|---|---|
| 노즈콘 | 천음속/wave drag 감소. 긴 ogive/conical 계열 검토 |
| 동체 직경 | 단면적 A가 항력에 직접 영향 |
| 핀 | 안정성, CP 위치, flutter 위험 |
| CP-CG static margin | 고속 안정성 확보. CG가 실제 조립/연료 소모에 따라 이동하면 재검토 필요 |
| 받음각 공력 | 작은 자세 오차가 큰 횡력/모멘트를 만듦 |
| 구조 강도 | 해수면 마하 1 동압은 약 72 kPa 수준 |
| 회수 방식 | 초기에는 낙하산 회수가 현실적. 동력 역추진은 장기 트랙 |

EDF로 마하 1을 노리는 것은 보수적으로 부적합하다고 본다.

| EDF 한계 | 이유 |
|---|---|
| inlet 문제 | 마하 근처 유입 공기를 팬 앞에서 안정적으로 처리해야 함 |
| fan tip Mach | 블레이드 끝단이 transonic/supersonic으로 가면 효율 급락 |
| 덕트 충격파 | 내부 압력 손실/실속 가능 |
| 전력 밀도 | 배터리+EDF는 화학 로켓 대비 고속 추진 여유가 작음 |
| net thrust 유지 | 정지추력 수치가 고속에서도 유지되지 않음 |

정리:

```text
EDF = 저속 TVC/GNC/착륙 연습용
마하 1 = 별도 고속 로켓/제트 비행체 설계 문제
```

## 안전 원칙 (모든 단계 공통)
- 회전체/추진계 테스트는 보호구·차폐·원격 거리 확보.
- LiPo 충방전·보관 안전. 모터/ESC 발열 모니터.
- 첫 비행은 항상 테더·저고도·개방 공간. 비상 정지(킬 스위치) 필수.
