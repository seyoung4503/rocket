# 로드맵

## 목표 (사용자 정의)
- 6개월 후 **마하 1** 도달.
- **발사 → 역추진(retro-thrust) 착륙**.
- **EDF 모터로 시작**, 제어는 **PID vs RL 비교 후 최종 RL**.
- RL 선택 이유: 헬리콥터 호버(자세 유지)가 RL 고전 예제이며, 추력편향 로켓 착륙이 같은 문제 구조.

## 핵심 현실 점검
| 항목 | 결론 |
|---|---|
| EDF로 마하 1 | ❌ 불가능. EDF는 공기 흡입식, 최고 ~200–400 km/h. 마하 1(≈343 m/s, 1235 km/h)은 고체/액체 로켓 영역. |
| 초음속 동력 역추진 착륙 | ⚠️ 아마추어 전례 없음(= Falcon 9 문제). 6개월 범위 밖. |
| 현실적 6개월 산출물 | ✅ 시뮬레이터 + EDF 호버/착륙 테스트베드에서 PID↔RL 검증. |

→ **제어 개발 트랙(EDF, 저속, 안전)** 과 **추진 트랙(고체 모터, 마하 1)** 을 분리. 둘을 한 기체에 합치는 것은 장기 목표.

## 단계 (Phases)

### Phase 0 — 시뮬레이션 기반 ✅ (진행 중)
- 6-DOF 강체 동역학 + RK4 ✅
- PID 호버 베이스라인 ✅
- Gymnasium RL 환경, 착륙 시나리오, 평가 지표 ⏳

### Phase 1 — EDF 호버/착륙 테스트베드 (sim → real)
- 시뮬레이터에서 PID vs RL 비교(정착 시간, 에너지, 외란 강건성).
- 도메인 랜덤화로 sim-to-real 격차 흡수.
- 실기: 김벌 EDF 추력대(짐벌 마운트), IMU/고도계, 비행 컨트롤러.
- 목표: 짧은 호버 → 위치 유지 → 저고도 강하 후 부드러운 착륙.

### Phase 2 — 고체 모터 TVC 호퍼 (아음속)
- 고체 로켓 모터 + TVC, 저고도 동력 상승/하강/착륙(BPS.space 류).
- 안전·법규(고출력 로켓 인증, 발사장) 검토 필수.

### Phase 3 — 마하 1 비행체 (별도 기체)
- 고체 모터로 초음속 도달, 회수는 우선 낙하산.
- 동력 역추진 착륙과의 결합은 그 이후의 연구 목표.

## 제어: PID vs RL
- **PID**: 캐스케이드(위치/고도 → 목표 추력벡터 → 자세 → 김벌). 해석 가능, 튜닝 직관적. 현재 베이스라인.
- **RL**: 정책망이 상태→(스로틀, 김벌) 직접 매핑. 비선형/제약/연료 최적 착륙에서 잠재 우위. 학습은 시뮬레이터에서.
- **비교 지표**: 정착 시간, 위치/자세 RMSE, 에너지(∫throttle), 착륙 속도, 외란/파라미터 변동 강건성.

## EDF 관련 주의
- 추력 응답 지연(스풀업)이 큼 → 빠른 자세 제어엔 불리. 자세는 주로 **김벌(TVC)** 로.
- 단일 김벌은 롤(축 회전) 제어 불가 → 핀/베인/리액션휠 또는 카운터 로터 필요.
